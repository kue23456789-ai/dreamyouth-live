GitHub 연결

처음 한 번만 등록하면 됩니다. 등록한 정보는 이 브라우저에만 저장되고, 저장 버튼을 누를 때 GitHub로 직접 전송됩니다 (다른 서버를 거치지 않아요).

  1. GitHub 우측 상단 프로필 → Settings
  2. 왼쪽 메뉴 맨 아래 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Repository access를 Only select repositories로 하고 이 저장소만 선택
  5. Permissions → Contents를 Read and write로 설정 후 생성
  6. 생성된 토큰(ghp_로 시작)을 복사해서 위 칸에 붙여넣기

⚠️ 이 토큰은 절대 다른 사람에게 공유하지 마세요. 이 사이트 저장소 하나만 접근하도록 범위를 좁혀서 만드는 걸 권장해요.
